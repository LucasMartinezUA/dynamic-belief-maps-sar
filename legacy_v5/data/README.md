# Data Files

This directory contains the archived legacy/v5 study tables. They are the frozen record of the
earlier study and are **not** reproduced from this repository, nor exercised by
`scripts/verify_public_artifacts.py`. Raw SAREnv datasets are not stored here; they are
downloaded separately into `sarenv_dataset/`.

Every file below carries the label `legacy/v5`.

| File | Status | Provenance | Use |
|---|---|---|---|
| `study_main_20260531_095441.csv` | legacy/v5 | Produced by `scripts/legacy_v5/comprehensive_study.py` for Study 5 on the main dataset. | Input to `legacy_v5/figure_scripts/analysis_cliff_delta_lmm.py`; used by `legacy_v5/figure_scripts/fig_pairwise_combined.py`; source for the `dynamic_3step` side of the tree-search comparison. |
| `study_datasets_20260531_095441.csv` | legacy/v5 | Produced by `scripts/legacy_v5/comprehensive_study.py` for Study 6 across the SAREnv datasets. | Input to `legacy_v5/figure_scripts/analysis_cliff_delta_lmm.py` for cross-dataset effects and per-dataset comparisons. |
| `cliff_delta_pairwise_likelihood.csv` | legacy/v5 | Produced by `legacy_v5/figure_scripts/analysis_cliff_delta_lmm.py` from `study_main_20260531_095441.csv`. | Pairwise Cliff's delta statistics; used by `legacy_v5/figure_scripts/fig_pairwise_combined.py`. |
| `cliff_delta_per_dataset_likelihood.csv` | legacy/v5 | Produced by `legacy_v5/figure_scripts/analysis_cliff_delta_lmm.py` from `study_datasets_20260531_095441.csv`. | Per-dataset effect-size table for `dynamic_3step` against the geometric baseline. |
| `lmm_lrt_likelihood.csv` | legacy/v5 | Produced by `legacy_v5/figure_scripts/analysis_cliff_delta_lmm.py`. | Linear mixed-model summary with LRT interaction test. |

| `per_dataset_dynamic_3step_vs_pizza_likelihood.csv` | legacy/v5 | Produced by `scripts/legacy_v5/extra_studies.py` from the Study 6 dataset CSV. | Archived per-dataset post-hoc comparison of `dynamic_3step` against `pizza`. |
| `nstep_sweep.csv` | legacy/v5 | Produced by `scripts/legacy_v5/nstep_sweep.py`. | Input to `legacy_v5/figure_scripts/fig_nstep_sweep.py`; reports likelihood and runtime as a function of lookahead depth. |

| `teaser_cells_dyn3_fail1_seed49.npy` | legacy/v5 | Produced by `legacy_v5/figure_scripts/capture_teaser_data.py`. | Observed-cell mask for the failed-drone `dynamic_3step` condition in the teaser figure. |
| `teaser_perdrone_pizza_fail1_seed43.npz` | legacy/v5 | Produced by `legacy_v5/figure_scripts/capture_teaser_data.py`. | Per-drone observed cells for coloring the geometric-baseline side of the teaser figure. |

| `teaser_likelihoods.txt` | legacy/v5 | Produced by `legacy_v5/figure_scripts/capture_teaser_data.py`. | Likelihood values for the failed-drone teaser conditions. |

The release flow is defined in `scripts/run_full_pipeline.sh`; the legacy v5 pipeline is
